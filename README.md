# Firebase Monorepo

This monorepo handles multiple applications and shared packages, integrated with Firebase.

## Structure

- `apps/`: Applications (Next.js, etc.)
- `packages/`: Shared libraries (UI, Configs, etc.)

## Getting Started

1.  `npm install`
2.  `npm run dev` (starts all apps)
3.  `npm run build` (builds all apps)
